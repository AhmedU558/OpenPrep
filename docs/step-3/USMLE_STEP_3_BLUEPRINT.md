For examinations using software introduced March10,2026: Day1 has232 MCQs in twelve30-minute blocks; Day2 has180 MCQs in nine30-minute blocks plus13–14 CCS cases, each10 or20 minutes. The older official overview still displays six-block timings; the dated update and current Step3 exam page resolve that inconsistency. OpenPrep's current MCQ engine is reusable; this expansion does **not** implement or claim CCS simulation equivalence.

## Primary-system allocation

Targets are editorial counts within official percentage ranges, not predictions of a particular examination form. Systems with grouped official categories remain grouped in sidecar metadata while using existing database taxonomy. Nutrition is an overlapping discipline and is not added to the primary total.

Nutrition target:170 overlapping items (17%, within the official15–20% discipline range). It must be substantively tested, not a cosmetic dietary detail. Track age group, setting and service line separately: internal medicine, emergency/critical care, surgery/perioperative care, obstetrics/gynecology, pediatrics, psychiatry, prevention and longitudinal outpatient management must all appear. Infectious disease and hematology/oncology map both to relevant organs and the grouped multisystem category.

Competency targets: diagnosis350; management340; evidence appraisal/PBLI120; applied foundational science115; communication/professionalism/patient safety75. The official overarching bands are33–36%,32–35%,11–13%,11–12%,7–9% respectively. Management subcategories overlap their parent and are not additional quotas. Day1/FIP versus Day2/ACM tags describe instructional emphasis, not an attempt to replicate the complete official examination.

Actual coverage will be computed from authored records in the manifest. A target is not authored coverage; unresolved clinical/rights review never counts as practice readiness.
