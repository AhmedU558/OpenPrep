# Support

Read [README](README.md), [architecture](docs/architecture.md), [deployment](docs/deployment.md) and [import instructions](docs/question-import-format.md). Search existing issues before opening a non-security bug/feature request. Include revision, Node/browser/OS versions, reproduction steps and synthetic sanitized examples. There is no support SLA or promised clinical review service.

Content errors can use the app's Report an error workflow, which sends reports to that instance's content admins. This is not a private security channel. Medically unreviewed educational content must not guide personal care decisions.

Do not report vulnerabilities in public issues or PRs. GitHub private reporting is currently disabled and no active private contact is configured: a RELEASE BLOCKER. Check [SECURITY.md](SECURITY.md) and wait for an authorized private channel. Conduct reporting also requires configuration/maintainer approval (CODE_OF_CONDUCT.md). Never post credentials, personal contacts, patient/student data, private complaints or database dumps.
